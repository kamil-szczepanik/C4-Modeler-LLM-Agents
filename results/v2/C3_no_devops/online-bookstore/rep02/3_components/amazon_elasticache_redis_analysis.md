## Overview
The Online Bookstore system provides scalable e-commerce capabilities for browsing, purchasing physical and electronic books, and viewing recommendations. It utilizes Amazon ElastiCache (Redis) as a high-performance caching and session management layer to meet sub-2-second performance goals under high user load.

## Key Elements
- **Session Store Component**: Manages ephemeral user sessions and shopping carts using Redis Hashes.
- **Product & Catalog Cache Component**: Caches serialized book details and hot categories via the Cache-Aside pattern.
- **Recommendation Cache Component**: Stores pre-computed recommendation lists generated by the Recommendation Service.
- **Core E-Commerce API & Recommendation Service**: Client applications interacting with the cache layer.
- **AWS Infrastructure**: Amazon ElastiCache (Redis) Replication Group, AWS KMS, AWS Secrets Manager, and Amazon CloudWatch Logs.

## Relationships
- **Core E-Commerce API -> Session Store Component**: Reads and writes session and cart data [Redis RESP protocol over TLS/TCP]
- **Core E-Commerce API -> Product & Catalog Cache Component**: Retrieves cached catalog data [Redis RESP protocol over TLS/TCP]
- **Recommendation Service -> Recommendation Cache Component**: Populates recommendation lists [Redis RESP protocol over TLS/TCP]

## Technology Stack
- **Amazon ElastiCache (Redis)**: Multi-AZ replication group with automatic failover for high availability (99.95% uptime).
- **Redis RESP protocol over TLS/TCP**: Secure transport protocol for all inter-container communications.
- **AWS KMS**: Enables mandatory encryption-at-rest for GDPR and CCPA compliance.
- **AWS Secrets Manager**: Manages and rotates Redis AUTH tokens securely.
- **Amazon CloudWatch Logs**: Captures Redis slow logs and engine logs for security auditing.

## Rationale
This architecture ensures 99.95% uptime and sub-2-second page loads for 1 million MAU by offloading database read traffic and preventing cart loss during failovers. Strict VPC isolation, IAM controls, and AWS KMS encryption fulfill rigorous GDPR, CCPA, and OWASP security constraints.
